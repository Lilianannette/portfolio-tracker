# Portfolio Tracker

Application personnelle de suivi de portefeuille boursier.
Projet d'apprentissage (OOP, design patterns, architecture, TDD) sur 1 an.

## Objectif
Aider un investisseur particulier à suivre son portefeuille et à savoir
ce qu'il a réellement gagné, frais compris.

## Périmètre (lot 1)
- Prix de revient d'une position (moyenne pondérée, frais de courtage inclus)
- Valorisation d'une position au cours actuel
- Plus-value réalisée vs latente
- Traitement des frais non rattachables

## Hors périmètre
Pas d'interface graphique, pas de multi-utilisateur, pas de fiscalité,
pas de déploiement. (Voir cahier des charges pour le détail.)

## Stack
Java 21 · Spring Boot 3.x · Maven · JUnit 5

## Lancer le projet
(à compléter quand le code existera)

./mvnw spring-boot:run
